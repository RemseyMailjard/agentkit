# Lab Generator v0.1

Third AgentKit plugin by Skills4-IT.

## Skills

- `create-lab`
- `create-challenge`
- `review-lab`
- `test-lab`
- `adapt-lab`

## Core teaching model

```text
explain
→ demonstrate
→ guide
→ practice
→ challenge
→ reflect
```

## Principle

A lab is not documentation. It is a designed learning experience with an observable
goal, realistic scenario, environment check, learner actions, checkpoints,
challenge, troubleshooting and expected result.

## Cross-plugin use

Lab Generator can orchestrate technical capabilities from other AgentKit plugins.

Examples:

- .NET Reviewer → identify problems → Lab Generator → create learner exercise
- MCP Builder → build MCP capability → Lab Generator → wrap it in a hands-on lab
