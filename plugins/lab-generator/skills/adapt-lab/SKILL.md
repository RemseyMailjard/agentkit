# Adapt Lab

Preserve the learning goal while changing the path appropriately.

## Adaptation dimensions

- beginner / intermediate / advanced;
- shorter / longer duration;
- classroom / online / self-paced;
- restricted permissions;
- no-cloud fallback;
- different tooling or language;
- more guided / less guided;
- trainer-led demo vs participant exercise.

## Workflow

1. Identify the original learning objectives.
2. Identify the new audience/constraint.
3. Keep only content that serves the target outcome.
4. Adjust prerequisites.
5. Adjust scaffolding and number of steps.
6. Adjust challenge difficulty.
7. Update checkpoints and troubleshooting.
8. Re-estimate timing.
9. State what was removed, simplified or deepened.

## Output

Return:

1. adaptation summary;
2. revised lab;
3. changed assumptions;
4. timing estimate;
5. tradeoffs introduced.

## Boundary

Do not redesign the whole course. If the request concerns curriculum structure,
route to Training Creator when that plugin becomes available.
