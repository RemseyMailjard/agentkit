# Review Lab

Review before rewriting.

Check scenario, objectives, prerequisites, environment setup, sequencing,
checkpoints, expected results, challenge quality, troubleshooting, cleanup,
timing and audience fit.

Separate blockers from improvements and never claim execution unless it actually ran.
