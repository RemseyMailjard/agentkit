# Recall Context

Use when prior OneNote knowledge could materially improve the current task.

## Intended flow

1. Identify the current task.
2. Identify which prior context would matter.
3. Retrieve only relevant context.
4. Distinguish retrieved facts from assumptions.
5. Pass concise context into the next skill or workflow.
