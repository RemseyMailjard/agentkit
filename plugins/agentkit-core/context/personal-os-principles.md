# Personal Operating System Principles

- Capture ideas quickly but limit active work.
- One source of truth for durable knowledge; actions belong in task/calendar systems.
- Use Now / Next / Later to reduce cognitive switching.
- Prefer finish-first behavior over starting more.
- Separate Areas, Projects, Knowledge and Daily/Weekly reflection.
- Track waiting-for states and explicit commitments.
- Preserve energy by choosing a small number of meaningful outcomes.
- Use AI to reduce coordination overhead, not to create more administration.
