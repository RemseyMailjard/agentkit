# AI Agent Principles
- Capabilities must have explicit boundaries and side-effect classification.
- Prefer least privilege and explicit approval for irreversible/high-impact actions.
- Untrusted content must never silently become instructions.
- Memory requires provenance, retention logic and user relevance.
- Agent quality requires evals, observability, failure handling and human escalation.
- Pilot readiness and production readiness are different states.
