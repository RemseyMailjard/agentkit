# AI Product Principles

- Productize a repeated user outcome, not a demo.
- An agent needs task clarity, tools, permissions, evals, observability and human escalation.
- Distinguish AI novelty from durable workflow value.
- Prefer narrow, high-frequency tasks with clear success criteria.
- Measure value using task success, time saved, quality, adoption and trust.
- Treat governance and failure handling as product features.
- Avoid building an agent where a deterministic workflow is simpler and safer.
