# AgentKit Capability Principles
- Skills are the routing surface; micro-tools are internal composable operations.
- Micro-tools should have one responsibility, predictable outputs and explicit boundaries.
- Do not create a micro-tool when an existing one already captures the operation.
- Prefer reusable operations across domains.
- Personal context should live in shared principle files instead of being duplicated everywhere.
- Every user-facing Skill needs positive routing cases, negative boundaries and a clear completion contract.
- Optimize context cost continuously; detail belongs in deferred references when practical.
