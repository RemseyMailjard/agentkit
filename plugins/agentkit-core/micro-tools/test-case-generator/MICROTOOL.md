# Test Case Generator

## Responsibility
Generate focused tests directly from requirements and risk.

Use engineering principles.

## Include
- positive path;
- negative path;
- boundary values;
- permissions/auth;
- empty/missing data;
- backend/integration failure;
- retry/idempotency for writes where relevant;
- regression risks.

## Output
For each test: purpose, input/precondition, action and expected result.

## Boundary
Do not create irrelevant exhaustive combinatorics.
