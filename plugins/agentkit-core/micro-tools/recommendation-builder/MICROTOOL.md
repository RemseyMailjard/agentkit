# Recommendation Builder

## Responsibility
Turn analysis into an executable recommendation.

Use work, consultancy and decision principles.

## Output
- recommended direction;
- why now;
- expected value;
- key trade-offs;
- quick win;
- structural next step;
- owner/dependency if evident;
- one concrete next action.

## Boundary
If evidence is insufficient, recommend the smallest validation step instead of pretending certainty.
