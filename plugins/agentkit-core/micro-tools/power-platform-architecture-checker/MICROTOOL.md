# Power Platform Architecture Checker
## Responsibility
Assess whether a Power Platform design uses appropriate app, flow, data and environment boundaries.
## Check
Dataverse vs SharePoint/List, connection references, solutions, environments, ALM, service accounts, DLP, ownership.
## Output
findings; severity; recommended architecture.
## Boundary
Do not perform broader analysis, rewriting, or decisions outside this responsibility; return findings for the parent Skill to act on.
