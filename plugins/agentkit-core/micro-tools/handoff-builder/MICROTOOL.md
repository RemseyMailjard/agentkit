# Handoff Builder

## Responsibility
Convert project or task context into a compact package another person or AI can continue from.

## Output
- goal;
- current state;
- decisions;
- completed work;
- open issues;
- next actions;
- dependencies;
- risks;
- source/evidence references when available.

## Boundary
Do not add speculative history. Prefer concise continuation context over a full transcript.
