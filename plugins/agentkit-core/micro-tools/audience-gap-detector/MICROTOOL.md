# Audience Gap Detector
## Responsibility
Detect the gap between current audience capability and the level required for successful training or adoption.
## Check
- current knowledge;
- role relevance;
- motivation;
- tool familiarity;
- environment access;
- likely misconceptions;
- language/accessibility;
- practical transfer risk.
## Output
gap; impact; evidence; design implication; mitigation.
## Boundary
Do not perform broader analysis, rewriting, or decisions outside this responsibility; return findings for the parent Skill to act on.
