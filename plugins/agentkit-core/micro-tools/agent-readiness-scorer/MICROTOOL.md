# Agent Readiness Scorer
## Responsibility
Score whether an AI agent is ready for pilot or production use.
## Factors
task clarity, tool reliability, permissions, security, eval coverage, observability, fallback, ownership, user value.
## Output
score; status; blockers; pilot conditions.
## Boundary
Do not perform broader analysis, rewriting, or decisions outside this responsibility; return findings for the parent Skill to act on.
