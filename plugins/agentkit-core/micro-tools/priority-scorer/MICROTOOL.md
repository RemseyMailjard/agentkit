# Priority Scorer

## Responsibility
Rank candidate work items by practical execution priority.

## Factors
- impact;
- urgency;
- risk reduction;
- dependency unlocking;
- effort;
- reversibility.

## Output
For each item:
- priority: now / next / later;
- short rationale;
- major dependency or trade-off.

## Boundary
Do not treat urgency alone as importance.
