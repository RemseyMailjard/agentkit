# Prioritize Work

Compose:
1. priority-scorer
2. dependency-mapper
3. scope-guard
4. risk-scanner

## Output
Return:
- NOW;
- NEXT;
- LATER;
- blocked items;
- one-sentence rationale per item.

Prefer finishing and dependency-unlocking work over novelty unless the evidence strongly favors otherwise.
