# Prepare Handoff

Compose:
1. handoff-builder
2. decision-extractor
3. next-action-finder
4. dependency-mapper
5. risk-scanner

## Output
Create a compact continuation package:
- goal;
- current state;
- important decisions;
- completed work;
- open issues;
- next action;
- dependencies;
- risks;
- references/evidence when available.

Optimize for continuation, not archival completeness.
