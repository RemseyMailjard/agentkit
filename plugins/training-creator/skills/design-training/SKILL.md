# Design Training

Use this progression where appropriate:

relevance → simple explanation → concrete example → deeper explanation →
trainer demo → guided practice → independent practice → challenge → reflection.

For each module define purpose, key concept, activity, evidence of learning and time.

Keep hands-on work aligned with objectives and real job tasks.

See [methodology](references/methodology.md) for the fuller delivery pattern.
