# Review Training Readiness

Review objective alignment, labs, assessment, prerequisites, instructor preparation,
environment/access, dependencies, timing and fallback paths.

Return exactly one status:
- READY
- READY WITH RISKS
- NOT READY

List evidence, blockers, risks and required actions. Never infer environment verification.
