# Create Training Assessment

Assessment must measure the stated objectives.

## Assessment mix

Use a deliberate combination of:

- quick knowledge checks;
- scenario questions;
- mini-challenges;
- hands-on validation;
- troubleshooting tasks;
- explain-your-choice questions;
- final practical task where appropriate.

## Rules

- Positive/negative correctness is not the same as pass/fail.
- Avoid trivia that does not support job performance.
- Prefer application over recall for technical professionals.
- Keep end-user assessments practical and confidence-oriented.
- Every assessment item should map to an objective.
- Include expected answer or rubric.

## Output

Return:

1. assessment map by learning objective;
2. questions/tasks;
3. expected answer or rubric;
4. difficulty;
5. estimated time;
6. common misconceptions;
7. instructor debrief notes.
