# Reverse Engineer API

Produce an evidence-based capability map rather than copying endpoints into tools.

Return:
1. evidence inventory;
2. domains and entities;
3. endpoint-to-business-capability mapping;
4. auth and permission model;
5. schema and error observations;
6. proposed tools/resources/prompts;
7. evidence vs inference;
8. implementation plan.

Read [references/reverse-engineering.md](references/reverse-engineering.md) for classification guidance.
