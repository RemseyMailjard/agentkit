# Golden Workflow — MCP Training

## Goal

Demonstrate an end-to-end AgentKit workflow that combines Training Creator, MCP Builder and Lab Generator to design a practical MCP developer training.

## Workflow

1. Analyze the training need and audience.
2. Define measurable learning objectives.
3. Design the training agenda and instructor flow.
4. Use MCP Builder for technical design, review, security and testing.
5. Use Lab Generator for guided labs and challenges.
6. Create assessment and delivery-readiness artifacts.

## Acceptance criteria

- The workflow contains a complete training brief, objectives and agenda.
- The technical MCP content is capability-first and includes security/testing.
- At least three hands-on labs are present.
- Instructor briefing and readiness status are included.
- Risks and environmental blockers are explicit.
- Readiness is not marked READY unless the environment has actually been verified.
