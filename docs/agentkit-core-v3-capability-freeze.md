# AgentKit Core v3 — Capability Freeze

AgentKit Core v3 establishes the first intentionally bounded capability library.

The rule after v3:
1. do not add micro-tools merely because another label is possible;
2. first prove an uncovered recurring operation;
3. check overlap with existing tools;
4. add routing/boundary evals;
5. prefer improving composition and eval coverage over growing the taxonomy.

The next phase is consolidation, routing, evaluation and packaging—not unlimited taxonomy growth.
